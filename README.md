Food App is an online food-ordering platform similar to Zomato and Swiggy, designed mainly for middle-sized cities. It connects customers with local restaurants, allowing users to browse menus, order food, make payments, and track orders until doorstep delivery.

Main Features: Restaurant & menu management, food search, cart, order placement, online payment, order tracking, and order history.
